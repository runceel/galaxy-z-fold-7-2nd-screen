# Galaxy Z Fold7 サブモニター化

Galaxy Z Fold7 の開いたメイン画面を、USB 接続で Windows の拡張ディスプレイとして使うためのプロジェクトです。

**現在は計画段階です。アプリ、ビルド設定、検証済みの送信コマンドはありません。** Windows Arm64 / AMD CPU 搭載 x64 の両方を対象とします。
